# dvC Tools — Bản phát hành

Bộ công cụ SketchUp của Chung Do.

- [Tải bộ cài mới nhất](https://github.com/chungds36clone2-blip/ChungDo/releases/latest)
- [Xem các bản phát hành và ghi chú thay đổi](https://github.com/chungds36clone2-blip/ChungDo/releases)

## Cài đặt và kích hoạt

Tải file `.rbz`, mở SketchUp → Extension Manager → Install Extension và chọn bộ cài. Lưu công việc, đóng hết SketchUp rồi mở lại.

Bản **1.3.1** đã gắn nguồn GitHub và cơ chế cập nhật. Cài bản này thủ công một lần để kích hoạt, sau đó giữ tick **Thông báo khi có bản mới** trong dvC Settings.

## Cập nhật

Khi có bản mới phù hợp, dvC hiện bảng thông báo với phiên bản hiện tại, phiên bản mới và ghi chú. Đồng ý để tải, kiểm tra SHA-256 và chuẩn bị bản chờ. Phiên đang làm giữ bản hiện tại; bản mới được nạp sau khi đóng hết các phiên SU dùng bộ cài này rồi mở lại. Có thể từ chối, hủy tải hoặc ẩn tiến độ.

Tính năng tự cập nhật hỗ trợ SketchUp 2022+ trên Windows. Mỗi release có bộ cài RBZ, metadata và mã SHA-256. Chỉ tải file `.rbz` để cài qua Extension Manager.

Thông tin phiên bản ổn định: [latest.json](https://raw.githubusercontent.com/chungds36clone2-blip/ChungDo/main/latest.json).
