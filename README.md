# dvC Tools — Bản phát hành

Bộ công cụ SketchUp của Chung Do.

- [Tải bản mới nhất](https://github.com/chungds36clone2-blip/ChungDo/releases/latest)
- [Xem các bản phát hành](https://github.com/chungds36clone2-blip/ChungDo/releases)

## Cài đặt

Tải file `.rbz`, mở SketchUp → Extension Manager → Install Extension. Chọn bộ cài, sau đó lưu công việc, đóng hết SketchUp và mở lại.

## Cập nhật

Thông tin phiên bản ổn định được cung cấp qua [latest.json](https://raw.githubusercontent.com/chungds36clone2-blip/ChungDo/main/latest.json). Mỗi bản phát hành có bộ cài, ghi chú thay đổi và mã SHA-256.

Bản 1.2.0 đã chuẩn bị mục kiểm tra cập nhật trong Settings; bản cài 1.2.0 ban đầu chưa gắn nguồn và chưa có cơ chế tự cài. Cơ chế mới cần một bản kích hoạt được cài thủ công lần đầu.
